# لوحة إدارة عقاري

هذه الصفحة مخصصة للإدارة فقط. قبل الإنتاج يجب ربطها بمصادقة Admin حقيقية وقاعدة بيانات وخدمة تخزين صور. لا تضع كلمة المرور أو مفاتيح API داخل الكود أو GitHub.

## سير الموافقة
1. صاحب العقار ينشئ الإعلان.
2. الحالة `pending`.
3. الإدارة تراجع الصور والبيانات.
4. `approved` يظهر الإعلان للمستخدمين في المحافظة المحددة.
5. `rejected` يبقى مخفياً مع سبب الرفض.
