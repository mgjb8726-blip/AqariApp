# عقاري | Aqari

تطبيق عقاري عربي للسوق العراقي، يبدأ من كركوك ويدعم جميع المحافظات العراقية.

## الفئات
منازل، شقق، قطع أراضي، مشتملات، محلات، مخازن.

## تجربة المستخدم
- الزائر يدخل مباشرة بدون إنشاء حساب.
- الزائر يستطيع التصفح والبحث وفتح تفاصيل العقار.
- رقم صاحب العقار مخفي عن الزائر.
- إنشاء الحساب يتيح اختيار: **زبون** أو **صاحب عقار**.
- الزبون يستطيع المفضلة والتواصل مع صاحب العقار.
- صاحب العقار فقط يستطيع إضافة ونشر العقارات.
- صاحب العقار يستطيع إدخال العنوان والمحافظة والمنطقة والسعر والمساحة والوصف.

## التقنية
React Native + Expo + TypeScript، بواجهة عربية RTL.

## التشغيل
```bash
npm install
npx expo start
```

ثم افتح المشروع عبر Expo Go أو المحاكي.

## Backend لاحقاً
هذه النسخة تستخدم بيانات محلية للتجربة. عند ربط Backend يجب تطبيق صلاحيات الأدوار على الخادم أيضاً، خصوصاً عدم إرسال رقم الهاتف للزائر، والتحقق من أن دور المستخدم `owner` قبل قبول نشر عقار.

## الحالة
هذه نسخة MVP قابلة للتشغيل والعرض، ومهيأة للمرحلة التالية: Backend حقيقي، مصادقة، تخزين صور، خرائط، إشعارات، ومراجعة/توثيق الإعلانات قبل النشر التجاري.
