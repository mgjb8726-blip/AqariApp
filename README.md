# عقاري | Aqari App

تطبيق عقاري عربي مخصص للسوق العراقي، يبدأ من **كركوك** ويدعم جميع المحافظات العراقية.

## الفئات
- منازل
- شقق
- قطع أراضي
- مشتملات
- محلات
- مخازن

## الحالة الحالية
نسخة MVP منظمة باستخدام React Native + Expo + TypeScript، مع دعم واجهات عربية وRTL، وتشمل:
- الصفحة الرئيسية
- تصنيفات العقارات الستة
- البحث والتصفية حسب الفئة والكلمات
- بطاقات العقارات
- صفحة تفاصيل العقار
- الاتصال بصاحب العقار
- التواصل عبر WhatsApp
- طبقة API بسيطة قابلة للاستبدال بواجهة Backend لاحقاً

## التشغيل
```bash
npm install
npx expo start
```
ثم افتح التطبيق عبر Expo Go أو شغّل:
```bash
npm run android
# أو
npm run ios
```

## Backend لاحقاً
كل بيانات العقارات تمر من خلال `src/services/api.ts`، لذلك يمكن استبدال البيانات التجريبية بـ REST API أو Firebase/Supabase بدون إعادة بناء واجهات التطبيق من الصفر.

## ملاحظات
صور البيانات الحالية تجريبية لأغراض التطوير. قبل النشر التجاري يُفضّل استبدالها بصور العقارات المرفوعة من المستخدمين، وإضافة المصادقة، رفع الصور، الخرائط، الإشعارات، وقاعدة البيانات.
