# عقاري — User Flow

## 1. الزائر
يفتح التطبيق مباشرة بدون تسجيل حساب.

يمكنه:
- تصفح العقارات.
- البحث والتصفية.
- فتح تفاصيل العقار.

لا يمكنه:
- رؤية رقم صاحب العقار.
- الاتصال أو فتح واتساب لصاحب العقار.
- حفظ المفضلة المرتبطة بالحساب.
- نشر عقار.

عند محاولة الوصول لميزة محمية تظهر دعوة واضحة لإنشاء حساب.

## 2. إنشاء الحساب
يختار المستخدم نوع الحساب:

### زبون
للتصفح المتقدم، المفضلة والتواصل مع أصحاب العقارات.

### صاحب عقار
لإضافة ونشر وإدارة العقارات الخاصة به.

## 3. صاحب العقار
بعد تسجيل الدخول تظهر له لوحة خاصة تشمل:
- إضافة عقار.
- رفع عدة صور.
- اختيار واحدة من الفئات الست.
- اختيار المحافظة والمنطقة.
- السعر والمساحة.
- عدد الغرف والحمامات عند الحاجة.
- وصف العقار.
- رقم التواصل.
- إدارة وتعديل وإخفاء إعلاناته.

## 4. قاعدة الأمان
إخفاء رقم الهاتف يجب أن يكون مطبقاً أيضاً في Backend/API لاحقاً، وليس في واجهة React Native فقط. الزائر لا يحصل أصلاً على رقم الهاتف من API.
